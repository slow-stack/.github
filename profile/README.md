# slow-stack

> A slow study in code and curiosity.

Open-source tools for AI agents — memory, audits, and the plumbing in between.

## Projects

- **[mneme](https://github.com/slow-stack/mneme)** — Cross-session memory for DeepSeek Harness. Offline & private; auto-consolidates in its sleep (autoDream)
- **[euthyna](https://github.com/slow-stack/euthyna)** — The audit AI coding agents can't skip: deterministic facts (git history, test coverage) plus six-gate claim adjudication
- **[ponte](https://github.com/slow-stack/ponte)** — Persistent SSH reverse-tunnel daemon CLI. Auto-reconnects with exponential backoff + jitter
- **[persistbench-sycophancy](https://github.com/slow-stack/persistbench-sycophancy)** — PersistBench × mneme: does cosine-threshold memory gating reduce sycophancy? Full-run analysis (n=200 × 2 arms, qwen3:8b, LLM-as-judge)
- *(more coming)*
